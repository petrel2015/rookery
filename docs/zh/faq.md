# 常见问题

[English](../en/faq.md) | 简体中文 · 文档[索引](./index.md) · 主 [README](../../README.zh.md)

### 有英文界面吗？

没有。展示墙的 UI 只有中文（分类片、按钮、头部文案）；v0.1.0 没有
语言切换。你正在读的文档是双语的。i18n 不在路线图上——见
[数据驱动设计的「非目标」](./features/data-driven-wall.md#非目标)。

### 在线演示在哪？

站点尚未部署（2026-08-27 核实）。构建产物是静态目录；
[部署指南](./deployment.md)有一页配方；上线后 README 的演示区会补上
地址。

### 我能用 Rookery 展示我自己的项目吗？

代码在 GitHub 上，可以 fork——但注意**尚未选择许可证**（见 README 的
「许可证说明」）：默认保留所有权利，超出个人实验范畴的使用请先开
Issue 询问。技术上，改造就是替换 `src/data/projects.js` 与
`public/covers/`——没有任何其它代码与具体项目绑定。

### 为什么封面图放在本仓库里，而不是热链到各项目？

这样展示墙在被链接的仓库改名、Pages 站点搬家或下线时也不会裂图。
每张封面都是从项目自己的 `docs/img/` 复制来的副本。见
[数据驱动的项目墙](./features/data-driven-wall.md#方案概览)。

### 没有截图的项目会怎样？

得到一张生成的占位封面：坐标纸底纹 + 项目首字（中文名取首字，英文
名取前两字母）+ 红点。看起来是有意的设计，不是坏了。见
[使用指南 · 封面图建议](./usage.md#封面图建议)。

### 站点会收集我的数据吗？

无统计、无 cookie、无运行时网络请求——唯一存储的是你在
`localStorage` 里的主题与视图选择。细节（含确切的键名与清除方法）见
[隐私说明](./privacy.md)。

### 能托管在子路径或自定义域名下吗？

都能——构建用相对 base，同一个 `dist/` 无需重构建即可用于
`https://user.github.io/rookery/`、自定义域名或任意嵌套路径。见
[部署指南](./deployment.md)。

### 有后端、API 或 GitHub 集成吗？

没有。所有内容构建期来自 `src/data/projects.js`。展示墙运行时不调用
GitHub API，也不拉取仓库数据。

### 能离线用吗？是 PWA 吗？

不能 / 不是。没有 Service Worker，除浏览器常规缓存外没有离线模式。
有时对墙上项目（如 QR·STUDIO）的「离线」描述说的是那些项目自身的
能力，不是 Rookery 的。

### 为什么没有我想要的分类（比如「文章」「设计」）？

分类是固定集合（`ext` / `tool` / `game`），与数据定义在一起。新增
分类 = 改 `CATEGORIES` 一行 + 给项目归类——刻意做成代码变更而非运行
时功能。见[当前局限](./features/data-driven-wall.md#当前局限)。
